RS-X Compiler & IntelliSense Spec

--------------------------------------------------
GLOBAL CONTEXT
--------------------------------------------------

RS-X is a declarative reactive system where expressions are written as strings:

    rsx('a + b.method().result')(model)

or:

    expressionFactory.create(model, 'a + b.method().result')

At runtime, these expressions are:
- parsed into an AST
- evaluated reactively
- tracked for fine-grained dependency updates

GOAL OF THIS PROJECT:

Move expression parsing and validation from runtime to compile time.

This enables:
- IntelliSense inside expressions
- early error detection (before runtime)
- elimination of runtime parsing cost
- direct AST reuse via ExpressionCache

--------------------------------------------------
CORE IDEA
--------------------------------------------------

Expressions are:
- NOT full JavaScript
- A constrained DSL (subset of JS expressions)

Defined by:
rs-x-expression-parser/lib/expressions/expression-parser.interface.ts

We must:
- parse this DSL at compile time
- validate it against TypeScript types
- cache the AST for runtime reuse

--------------------------------------------------
SUPPORTED ENTRY POINTS
--------------------------------------------------

1. rsx('...')(model)

2. expressionFactory.create(model, '...')
   where factory implements IExpressionFactory

IMPORTANT:
- Support must be type-based, not name-based
- Must work for:
    factory.create(...)
    getFactory().create(...)
    any IExpressionFactory implementation

--------------------------------------------------
SCOPE (v1)
--------------------------------------------------

SUPPORTED:
- string literal expressions only

NOT SUPPORTED:
- dynamic expressions
- template strings
- full JavaScript
- statements (if, class, loops, etc.)

--------------------------------------------------
ERROR MODEL
--------------------------------------------------

We distinguish 3 types of errors:

1. Semantic errors (TypeScript-based)

Example:
    rsx('a + b.method().uh')(model)

Error:
    Property 'uh' does not exist on value returned by 'b.method()'

2. Syntax errors (valid DSL but invalid syntax)

Example:
    rsx('a + ')

Error:
    '+' operator expects a right-hand operand

3. Unsupported expressions

Example:
    rsx('if (a) b.c else 0')

Error:
    'if' is not supported in RS-X expressions

MAIN PIPELINE
--------------------------------------------------

At compile time:

1. Detect expression
2. Resolve model type
3. Parse expression → AST
4. Validate AST against model type
5. Emit diagnostics if needed
6. Register AST in ExpressionCache
