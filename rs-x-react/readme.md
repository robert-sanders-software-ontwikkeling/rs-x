# @rs-x/react

React hooks integration for RS-X — bind expressions to your data models and make React components fully reactive without extra boilerplate.

**Docs:** [rsxjs.com](https://rsxjs.com)

---

## Installation

```bash
npm install @rs-x/core @rs-x/state-manager @rs-x/expression-parser @rs-x/react
```

## Build

```bash
pnpm run build:react
```
